# Kivu-Simstrat Model: For Methane Extraction Scenarios
This is the user-friendly model version adapted for Lake Kivu under the consideration of Methane extraction operations. 

# How to run the model
To succefully run the model and simulate methane extraction scenarios, the following steps are are necessary: 
## 1. Download / clone the model repository

~~~bash
link/or/path/to/be/passed
~~~

## 2. Install python
In case you don't already have installed python, download it and follow installation via the link below: 
~~~bash
link/for/python/installation
~~~
## 3. Install required packages
After getting your python environment ready, install the listed packages.
- pandas
- numpy
## 4. Required user-inputs
In the directory of where the downloaded model is saved, open the file named "extraction_user_inputs.json", then fill it accordingly.
## 5. Run the model
Open your terminal from the directory at where your downloaded model is saved, to launch a similar running syntax (below). 
~~~bash
python run_model_with_extraction.py extraction_user_inputs.json
~~~
